Distributed In-Memory Live NBA Box-Score & Telemetry Engine

Active development

A strongly consistent, distributed engine that ingests a rapid stream of play-by-play events from live games and replicates updated player stats across a server cluster, with no lag and no dropped events.

Built from scratch in Java 21+ using Virtual Threads for thousands of concurrent requests, a custom Raft consensus protocol over gRPC for replication, and off-heap Direct ByteBuffers to avoid GC pauses during rapid stat updates.
