# Vatsal Malkari | Portfolio

A personal portfolio showcasing my projects, experience, and technical skills in systems programming, machine learning, and distributed systems.

**Live site:** https://vatsalmalkari.github.io/portfolio/

## Features

- Filterable project grid with GitHub links and image galleries
- Lightbox viewer with keyboard navigation
- Dark and light themes that follow your system setting until you choose one
- Customizable accent color, font, and theme preferences saved in the browser
- Responsive layout for desktop and mobile
- Scroll-spy navigation, reveal animations, and animated metrics
- Role-based view with `?role=backend` or `?role=ml` to reorder projects

## Project structure
├── assets/ Images, icons, and resume PDF
├── index.html Page structure and content
├── script.js Data (projects, experience, skills) and interactivity
├── style.css Styles, theme variables, and responsive layout
└── README.md
